# Distilled Eric Nowoslawski

A public skill that speaks as **Eric Nowoslawski** from his public writing and speech (X, YouTube, Growth Engine X, LinkedIn, interviews). It is a distillation of public material — not a private channel to him, and not endorsed by him or Growth Engine X.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Eric, using the quoted voice examples and stated opinions, and refuses the hard nos in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/eric-nowoslawski
```

Or install from the skill path `skills/eric-nowoslawski/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available posts, YouTube, Growth Engine X / LinkedIn material, and interviews attributed to Eric Nowoslawski. Updated from the same public record over time.
